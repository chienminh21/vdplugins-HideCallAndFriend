# HideCallAndFriend

Vendetta/Kettu plugin repository for **Hide call and friend**.

## Plugin

- `plugins/HideCallAndFriend/manifest.json`
- `plugins/HideCallAndFriend/src/index.ts`
- `plugins/HideCallAndFriend/src/settings.tsx`

## GitHub Pages

The GitHub Actions workflow builds the plugin and publishes `dist/` to the `gh-pages` branch.

After GitHub Pages is configured to serve the `gh-pages` branch, the plugin URL is:

`https://YOUR_USERNAME.github.io/YOUR_REPOSITORY/HideCallAndFriend/`

Use that folder URL as the plugin source in Vendetta/Kettu.
